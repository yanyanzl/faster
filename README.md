# Faster v0.3.1 · 使用与打包说明

**中文** | [English](README.en.md)

成品：
- Windows：`Faster-0.3.1.exe`（单文件，双击运行）
- macOS：`Faster-0.3.1.dmg`（打开后把 Faster 拖进“应用程序”）

PyInstaller 不能跨系统打包——**Windows 版必须在 Windows 上打，Mac 版必须在 Mac 上打**。两种做法任选：

## 方法 A：GitHub 云端一键打包（推荐，不需要自己装环境）
1. 在 GitHub 新建一个仓库，把本文件夹的**全部内容**（含隐藏的 `.github` 目录）上传。
2. 打开仓库的 **Actions → Build Faster → Run workflow**。
3. 约 3~5 分钟后，在运行记录底部的 **Artifacts** 下载 `Faster-<版本号>-windows` 和 `Faster-<版本号>-macos`。
   （想发布成 Release：打个 tag，如 `git tag v1.0.0 && git push --tags`，会自动生成下载页。）

## 方法 B：在自己电脑上打包
- **Windows**：安装 Python 3.9+（勾选 Add to PATH）→ 双击 `build_windows.bat` → `dist\Faster-<版本号>.exe`
- **macOS**：终端运行 `bash build_mac.sh` → `dist/Faster-<版本号>.dmg`。脚本会自动建虚拟环境（不会遇到 externally-managed-environment 报错）。
  若提示缺少 tkinter：Homebrew 用户执行 `brew install python-tk`，或安装 python.org 的官方 Python。

## 首次运行的系统提示（未购买代码签名证书时都会出现，属正常）
- **Windows SmartScreen**：点“更多信息” → “仍要运行”。个别杀毒软件可能误报 PyInstaller 程序，可自行加入信任；
  想彻底消除需购买代码签名证书对 exe 签名。
- **macOS**：提示“无法验证开发者/已损坏”时，在“应用程序”中**右键 → 打开**；仍不行则终端执行：
  `xattr -cr /Applications/Faster.app`。（正式分发需 Apple Developer 账号签名+公证。）
- **Intel 芯片的 Mac**：`macos-latest` 产出的是 Apple 芯片版。Intel 版请用方法 B 在 Intel Mac 上打包。

## 使用注意
- “自动清理”的定时任务记录的是程序所在路径。**启用定时任务后请不要移动/重命名程序**；若移动了，重新点一次“保存并启用定时任务”。
- macOS 若要自动清理“文稿/下载”等文件夹，需在 系统设置 → 隐私与安全性 → 完全磁盘访问权限 中添加 Faster。
- 无界面执行一次清理：`Faster.exe --auto-clean`（加 `--dry-run` 为试运行）。

## 版本管理（v0.1.0 是基础版本）
- 版本号只改 `faster.py` 顶部的 `__version__`；界面标题、`--version`、dmg/exe 文件名、Mac 的应用信息都会自动跟随。
- 发布新版本：提交代码后打 tag，GitHub 会自动打包并发布（例如当前版本）：
  ```
  git add . && git commit -m "v0.3.1"
  git tag v0.3.1 && git push origin main v0.3.1
  ```
- 每个版本的改动记录在 `CHANGELOG.md`。

## 管理员权限怎么用
程序平时以普通用户运行（更安全），**只在需要时**单独提权，界面上带 🛡 的按钮或弹窗会引导你：

| 需要管理员的功能 | 怎么触发 |
|---|---|
| 系统级垃圾清理（Windows 系统临时/更新缓存、macOS /Library/Caches、Linux apt 缓存/日志） | 垃圾清理页 → 🛡 管理员清理系统级垃圾 |
| 停用/恢复系统级启动项（HKLM、/Library/LaunchAgents） | 正常点“停用选中”，失败时会提示“是否授权重试” |
| 完整的端口/进程扫描 | 风险扫描页 → 🛡 管理员权限扫描 |
| macOS 移除 /Applications 里的应用 | 卸载时失败会提示授权重试 |

授权窗口：Windows 为 UAC 弹窗；macOS 为系统密码框；Linux 为 polkit 窗口（需已装 pkexec）。
**Windows 想一次授权全部功能**：概览页点“以管理员身份重新启动”。
提权只执行内置的固定动作，不会执行任意命令。定时自动清理仍只清理用户级内容，不需要管理员。

## v0.2 钱包安全功能说明（“钱包安全”页签）
| 子页 | 做什么 | 要点 |
|---|---|---|
| 钱包文件 | 找出本机钱包文件并标注云同步风险 | 这些文件会被所有清理功能自动跳过 |
| 区块链数据 | 识别节点/钱包数据目录和可重新同步的大小 | 只提示，不自动删除 |
| 密钥泄露扫描 | 找明文保存的助记词/私钥 | 不回显内容；默认不读代码/配置文件（可勾选）；图片/截图、便签数据库、PDF 不在范围内 |
| 挖矿检测 | 找挖矿木马 | 你自己运行的矿工也会被标出（高危后面有说明） |
| 剪贴板守护 | 发现地址被替换；校验收款地址 | 需手动开启，只在内存里记录 |

**BIP39 词表**：助记词的“校验和验证”需要官方英文词表。打包版会在打包时自动下载并内置（`fetch_wordlist.py`，下载后做结构 + 官方测试向量双重校验，不通过就不用）。
从源码运行时，扫描前会询问是否下载（也可在“密钥泄露扫描”页点“查看助记词表”下载）。**没有词表时不检测助记词**（不再靠关键词猜测），只检测私钥。

**运行测试**：`python -m unittest discover -s tests -v`

**重要提醒**：Faster 永远不会向你索要助记词/私钥。扫描发现明文助记词/私钥时，最稳妥的做法是：把资产转到全新生成的钱包，新助记词抄写在纸上离线保存，再删除或加密旧的明文文件。固态硬盘上的“删除”不保证数据无法恢复。

## 诊断中心：一键诊断，按按钮解决（v0.3.1）
**怎么用**：在“概览”页点 **🔍 一键诊断**（或打开“诊断”页签点“开始诊断”）。只读检查，不会改动系统；快速诊断约 10~30 秒，可随时点底部“取消”。

**检查四大类**
| 类别 | 检查什么 |
|---|---|
| 性能 | 内存、交换空间、CPU、开机启动项数量、连续运行时间、Windows 电源计划 |
| 存储 | 磁盘剩余、可清理的垃圾、回收站占用；（深度）大文件、重复文件 |
| 安全 | 系统防护（防火墙 / Defender / Gatekeeper / SIP）、可疑启动项、挖矿木马、hosts 被改动；（深度）进程与端口、计划任务、临时目录里的可执行文件 |
| 钱包 | 云同步目录里的钱包文件和明文助记词/私钥、BIP39 词表是否就绪；（深度）整个主目录的钱包文件和明文密钥 |

**结果怎么看**：顶部是总的**健康分**和四类各自的分数（100 分起，每个“严重”扣 25、每个“注意”扣 10；“提示”不扣分）。每个问题是一张卡片：级别（严重 / 注意 / 提示 / 良好）、现状、建议，以及后面的**动作按钮**。默认只显示有问题的项目，勾选“显示正常项目”可看全部。

**按钮有两种**
- **直接执行**：清理垃圾、清空回收站、停用可疑启动项、停用影响高的启动项、结束占用高的程序、打开系统安全/防火墙/电源设置、下载 BIP39 词表……所有会改动东西的按钮都会**先让你确认**，做完卡片上显示“✓ 已处理”。
- **跳转**：带你到对应页面，并自动开始扫描（比如“查看大文件”会直接开始扫大文件）。

**目标页面也会列出建议操作**：诊断之后，相关页面顶部会出现“💡 建议操作（来自上次诊断）”，列出本页可以直接执行的动作和按钮——垃圾清理页（清理垃圾）、还原中心（清空回收站）、启动项 / 启动影响页（停用）、后台进程页（结束进程）、风险扫描页（打开系统安全设置）、钱包安全页（结束挖矿进程、下载词表）。没有建议时自动隐藏。

**深度诊断**：勾选“深度诊断”后会多做大文件、重复文件、整个主目录的钱包与密钥扫描、深度风险扫描，可能要几分钟。

“诊断”页签里还有两个子页：**启动影响**（估算每个启动项的内存和平均 CPU，按影响排序，可直接停用；按“正在运行的进程”估算，不是精确的开机耗时）和 **前后对比**（每次清理、停用启动项、结束进程都会自动记录“前/后”状态，可任选两条对比）。

## 取消、进度与还原中心（v0.3）
**取消与进度**：垃圾扫描、大文件、重复文件、钱包文件、区块链数据、密钥泄露扫描、诊断等耗时操作，底部状态栏会显示当前进度和一个“取消”按钮；取消后保留已扫描到的部分结果。

**还原中心**（统一查看和还原 Faster 移走/停用的东西）：
- **工具回收站里的文件**：可还原到原位置；原位置已有同名文件时自动加“(已还原)”后缀，**绝不覆盖**。也可永久删除或清空。
- **系统回收站里的文件**：只保留记录（90 天），请点“打开系统回收站”自行还原。
- **已停用的启动项**：可还原（系统级的会提示授权）。
- “垃圾清理”删除的缓存是**永久删除**的，不在此列；钱包文件永远不会被移走。
- 注意：文件移入回收站**不会立即释放磁盘空间**，清空回收站后才真正释放。

命令行菜单 `10`：性能诊断（只读）。

## 界面语言（中文 / English）
- 默认跟随系统语言。切换方式任选其一：
  - 图形界面：“概览”页顶部的 **语言 / Language** 下拉框（跟随系统 / 简体中文 / English），选择后按提示重启即可；
  - 命令行菜单：选 `9`；
  - 命令行参数：`--lang en` 或 `--lang zh`（仅本次运行）；环境变量 `FASTER_LANG=en`；
  - 设置文件：`~/.faster/settings.json` 里的 `"language"`（`zh` / `en` / `auto`）。
- 定时自动清理、管理员辅助进程使用同一语言设置，日志和报告也用当前语言书写。
- 打包脚本（`build_*.bat/.sh`、`fetch_wordlist.py`）的控制台输出目前仅有中文。
- **想增加一种新语言**：复制 `faster_i18n_en.py` 为 `faster_i18n_xx.py`，把译文填进 `CATALOG`（键是中文原文，`{0}` `{1}` 占位符必须保留）；在 `faster_i18n.py` 的 `LANGUAGES` 和 `_CATALOGS` 各加一行；运行 `python tools/i18n_check.py` 检查缺漏。
- **开发约定**：面向用户的文字一律写成 `tr("中文原文 {0}", 参数)`，不要直接写中文字符串（正则表达式除外）；`tests/test_i18n.py` 会检查。

## BIP39 词表说明
- 来源：<https://github.com/bitcoin/bips/blob/master/bip-0039/english.txt>（官方英文词表，2048 个单词）。程序下载的是同一文件的原始版本，并做双重校验：结构（2048 个互不相同、按字母排序、前 4 个字母可唯一区分）+ BIP39 官方测试向量；不通过就不使用。
- **词表是固定不变的**：改动任何一个单词都会让已有钱包的助记词失效，所以英文词表自 2013 年以来没有变化；将来只可能新增语言，不会修改已有词表。
- **有多种语言**：官方仓库还有日语、韩语、西班牙语、简体中文、繁体中文、法语、意大利语、捷克语、葡萄牙语共 9 种。现实中绝大多数钱包使用英文；Faster 目前只检测英文词表。
- 另外几种“助记词”不是 BIP39，也未覆盖：Electrum 自有的种子格式、Trezor 的 SLIP39（分片备份，1024 词表）、Monero 的 25 词助记词。
- **内置到程序**：打包时由 `fetch_wordlist.py` 下载、校验并打进程序。想让打包完全不依赖网络：在有网的电脑上运行一次 `python fetch_wordlist.py`，把生成的 `bip39_english.txt` 提交进仓库即可。
- 在“钱包安全 → 密钥泄露扫描 → 查看助记词表”里可以查看全部单词、来源、文件路径和 SHA-256。

## FAQ
  ```
  macOS 的 Gatekeeper 可能拦截：Faster 还没有 Apple 的开发者签名和公证，所以系统无法确认它没问题。不是程序有问题，用下面任一方法放行即可。

  方法一：系统设置里放行（macOS 15 Sequoia 及以后）
  先把 Faster 从 dmg 拖进「应用程序」。
  双击打开一次，出现上面的提示后点「完成」或「好」。
  打开「系统设置 → 隐私与安全性」，往下滚动，找到「已阻止使用 Faster」，点旁边的「仍要打开」。
  输入开机密码或用触控 ID 确认，之后再点「打开」。
  这个操作只需要做一次，以后可以正常双击打开。

  方法二：一条命令去掉隔离标记（最省事）
  打开「终端」，执行：
  xattr -cr /Applications/Faster.app

  然后正常双击打开。如果你的 Faster.app 不在「应用程序」里，就把路径换成实际位置。这条命令只是去掉系统给下载文件打的「来自网络」标记，不会修改程序本身。

  方法三：较早的 macOS（14 及以前）
  在「应用程序」里右键 Faster → 打开 → 再点「打开」，同样只需一次。
  ```
